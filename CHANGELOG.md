# Changelog

## [0.2.0]

### Added
- `edit-grade` and `remove-grade` commands
- `report --csv` to export a report as CSV
- `list` command with `--sort id|name|average`
- `stats` command for module statistics
- `import-csv` command for bulk grade entry
- `--version` flag and `python -m gradetracker`

### Changed
- CI also runs on Python 3.13

## [0.1.0]

### Added
- Students, grades and credit-weighted averages
- JSON storage
- `add-student`, `add-grade` and `report` commands
- UK degree classification in reports
- Test suite and GitHub Actions CI
